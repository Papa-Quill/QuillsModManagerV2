
# Quill's Mod Manager v2

The successor mog champion to QMM v1 is finally here.

## Features
- Highly customizable configuration
- Profile specific save management and backup system
- One-click profile deployment and removal
- Steam user specific profile support
- Background efficiency mode while the game is running
- Support for mod extenders
- Load order aware deployments
- Global save safety and backups
